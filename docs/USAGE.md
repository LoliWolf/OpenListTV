# OpenList TV 使用说明

适用版本：1.0.0。面向 Android TV、安卓投影及安卓设备；需要你有权访问的 OpenList 服务和账号密码。客户端不提供网盘空间、不修改服务器文件，也不会自动连接演示服务器。

## 安装与更新

1. 从 [GitHub Release](https://github.com/LoliWolf/OpenListClientAndroidTV/releases/tag/v1.0.0) 下载 `OpenListTV-1.0.0.apk`。
2. 将 APK 传到设备，按系统提示允许该安装来源，完成安装。不要绕过设备自身的安全限制。
3. 更新已有版本时直接覆盖安装，不要先卸载或清应用数据。同包名、同签名会保留站点、会话、排序、轮播参数和最近播放进度；服务端撤销的会话仍需重新登录。

最低声明 Android 6.0 / API 23。主要验证 Android 14 ARM64 TV 模拟器；Android 6、32 位、真机 4K 和各品牌长稳仍需分别验证，不代表所有设备已测试。

## 连接 OpenList

1. 打开应用，填写站点名称、完整服务器地址、账号和密码。服务部署在子路径时，保留该前缀。
2. 推荐 HTTPS。局域网使用 HTTP 时须明确勾选“允许此站点使用 HTTP”；这是明文传输，不要用于不可信网络。
3. 遥控器上下切换输入框，确认键打开系统输入法，返回键关闭输入法；选择“连接站点”，成功后显示目录列表。
4. “站点”可添加或切换多站点，同一时刻只有一个活动站点。会话加密保存，不主动保存原始密码；目录密码只在当前会话记忆。

一期仅支持账号密码，不支持访客、TOTP、SSO、LDAP、Passkey。不要关闭服务端安全要求来适配客户端。

## 浏览、排序和播放

上下选择，确认进入目录或播放，返回上一级。“排序”支持名称自然排序、修改时间、文件大小和服务器顺序；升降序与文件夹置顶按可用选项设置。“重新加载”重读列表，不执行服务端强制刷新。

图片自动显示缩略图，每页 100 项，仅当前页＋下一页，继续下翻才移动窗口。优先使用服务端预览，缺失时仅为可见图片生成预览。全局排序可索引全目录元数据，但不下载全库图片。

![横屏资源浏览](screenshots/landscape-browser.png)

点播支持设备可解码的图片、音乐和视频，提供 HLS、基础音轨及内嵌 / 同目录 SRT、VTT 字幕选择。大视频流式读取，5 GB 文件不要求 5 GB 运存；流畅程度还取决于网络、码率和设备解码器。

## 设置轮播

在当前目录选择“开始轮播”，设置模式、是否包含子目录、是否仅图片和时长，再选择“开始”。

| 选项 | 含义 |
| --- | --- |
| 顺序深度遍历 | 按目录顺序播放，可包含子目录 |
| 随机游走 | 随机选择资源及子目录，不等同于全库均匀随机 |
| 全目录树随机 | 扫描可访问目录树；扫描中可能重复，完成后按轮次抽取 |
| 图片秒数 | 1–3600 秒，新图显示后重新计时 |
| 视频 / 音频秒数 | 0 表示播放到结束，其他值表示最多播放该时长 |
| 预取音视频地址 | 只预取地址，不创建第二个播放器；不影响图片自动预加载 |

图片提前下载、解码下一张，准备好后直接替换，图片之间不插入加载文字或空白。慢网时延长当前图停留，不保证网络不足时仍按固定秒数切换。首次进入和真实错误仍显示必要提示。

<img src="screenshots/portrait-slideshow-settings.png" width="340" alt="竖屏轮播设置，数字框显示用途与秒单位">

只预加载一张，并按内存预算采样。无法解码且无低清源时轮播跳过；持续网络 / 鉴权 / 限流或连续多项失败时暂停。音视频不做本地实时转码，不承诺双视频无缝拼接。

## 遥控与横竖屏

| 场景 | 操作 |
| --- | --- |
| 文件列表 | 上下选择、确认打开，文件行上左右跳页 |
| 隐藏的播放器控制栏 | 确认暂停 / 继续，上下唤出按钮，返回退出 |
| 图片与轮播 | 左右前后项，或使用可见按钮 |
| 手动音视频 | 支持时左右快退 / 快进 10 秒 |
| Home / 休眠 | 暂停并释放资源，返回后手动继续 |

界面跟随系统横竖屏和深浅色。窄屏工具栏换行，大小与日期合并显示；旋转不应清空目录或重新启动轮播。第一次返回可能只收起控制栏，再按一次才退出。

## 常见问题

- 连接失败：检查完整地址、部署前缀、网络与证书。网络不可用不会清掉保存的站点；不提供“忽略所有证书错误”。
- 目录打不开：检查目录密码及账号权限，不要把目录权限问题当作必须重新登录。
- 资源不能播放：容器格式不代表内部编码一定可用。图片临时输入限 32 MiB；超限或无法解码会提示。4K SDR 按设备能力降级，HDR 不在 1.0.0 范围内。
- 大目录较慢：名称 / 时间 / 大小排序需完整索引；上限 10 万条 / 64 MiB。可缩小目录或到“设置”清缓存。
- 更新签名冲突：不要先卸载；核对是否为本项目原签名 Release，并向项目反馈。

反馈请附设备型号、系统、应用 / OpenList 版本、驱动、步骤和脱敏日志，不提交密码、令牌、完整签名 URL 或私人媒体。[飞书知识库](https://my.feishu.cn/wiki/LojHwxGlOiAofDk2JLocRIYinnb)仍遵循飞书自身访问权限。
