# OpenList TV 1.0.1-preview.11

预发布版，Android 6.0+，versionCode 15。稳定版仍为 1.0.0。

## 本次更新

- 简化原生界面：资源页四个常用入口，设置按类别分组，轮播参数通过摘要行分层编辑。
- 精简播放控制条，画面、音轨、字幕、定时和播放信息按需展开；保留遥控焦点和横竖屏状态。
- 优化大目录索引：按批读取元数据、边扫描边播放、深页游标查询；达到软件索引限额时继续播放已发现资源。
- 新增可选“超大库公平抽样”，最多保留一万候选，继续读取后续目录；可能重复，不保证每张都播放到。
- 复用最近范围的索引快照，可配置前台自动刷新；菜单键或播放菜单可手动刷新，先播旧索引，完成后切换。
- 修复同账号重连时索引快照被误清理、窄屏尺寸分类切换时播放器重建的问题。

保留此前的 HDR 系统播放链路、128 MiB 图片输入、无缝图片预加载、当前目录搜索与类型筛选、画面调整、左右长按加速快进退、前台下载和离线打开。

## 安装与更新

1. 下载 `OpenListTV-1.0.1-preview.11.apk`，直接覆盖安装，不要卸载或清应用数据。
2. 通过旧版检查更新时，先开启“参与测试版本”；新版入口为“设置 → 应用更新”。
3. 包名和签名保持兼容，账号、设置、播放进度和本机下载保留。设备限制安装时，使用设备支持的浏览器或文件安装方式，不绕过系统安全要求。

图片按内存预算采样；4K/HDR 取决于资源、网络与设备能力。索引仍共享 64 MiB 磁盘预算，普通随机候选最多十万、公平抽样最多一万；不代表无限库或全覆盖。不增加后台常驻、软件转码或后台自动刷新。
