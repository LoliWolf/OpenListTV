# 1.0.1 预览版

发布版本 `1.0.1-preview.11`，重新整理原生界面的视觉与交互，保留此前功能。[从 GitHub 预发布页下载安装包](https://github.com/LoliWolf/OpenListTV/releases/tag/v1.0.1-preview.11)；稳定版仍是 1.0.0。沿用原包名与签名，直接覆盖安装即可；不要卸载或清应用数据。

## 更简洁的操作入口

- 资源页保留“上一级”“搜索”“轮播”“更多”。横屏时工具栏与标题并排，竖屏时自动换行。排序、重新加载、根目录、站点、下载及设置都在“更多”里；文件行长按确认键仍可直接操作文件。
- 轮播配置先显示当前方案摘要。选择“播放方式”更换模式，选择“图片停留时间”“视频与音频时长”“定时停止”分别编辑；缓存复用、自动刷新、单次重扫与地址预取在“索引与高级选项”里。输入框仍有用途、单位和范围提示。
- 设置只在最终“开始”时保存。子面板取消不应用该面板的改动，整个轮播面板取消不保存任何草稿；“本次重新扫描”仍不保存到下次。
- 播放器仅显示上一项、暂停 / 继续、下一项和“更多”。画面设置、播放信息、音轨 / 字幕、定时停止、重试与退出移到“更多”；索引详情也从这里按需查看。确认暂停、左右切换 / 长按快进、返回收起 / 退出等遥控规则不变。
- 设置首页按应用更新、本机下载、站点与账号、存储与缓存、关于分组；更新开关与代理位于“应用更新”。清缓存与退出账号保留确认步骤。
- 浅色与深色界面统一焦点边框、文字层级与圆角。仍使用原生 View 和有界虚拟列表，不引入 UI 框架、模糊特效、字体下载或额外图片缓存。

## 沉浸式轮播与刷新

- 适用于“全目录树随机”和“超大库公平抽样”。轮播设置的“自动刷新索引”填 `0` 关闭（默认），或填 `5–1440` 分钟；保存后覆盖升级也保留。顺序遍历和随机游走不使用整树候选索引，不启动此刷新任务。
- 在前台轮播中按遥控器**菜单键**即可请求刷新；没有菜单键时，按上 / 下打开控制栏，在“更多”里选“刷新索引”。长按 / 重复点击不叠加任务。菜单键不会暂停播放或弹出控制栏。
- 刷新在另一磁盘候选区逐页构建，旧索引继续播放。成功后原子切换，当前图片及已预加载的下一项照常播放，随后从新索引取项；刷新后按新候选池重新计轮，可能再次播放之前的文件。新增文件纳入候选池不代表会立即播放到它。
- 自动刷新间隔从一次扫描结束计算，扫描未结束不启动下一次；使用快照启动时，若距上次更新已超过配置间隔，会先播放旧快照并请求刷新。不打开应用时不刷新；Home、休眠和退出取消任务，回来后需手动继续轮播。暂停但仍停留在前台时，刷新可继续。
- 索引状态仅在主动打开的控制栏显示：候选数、已读可播条目 / 目录数、上次更新时间、刷新进度与失败原因。不显示无法准确计算的整库百分比。控制栏隐藏后不轮询状态，不自动弹出完成 / 失败 / 索引限额提示，不添加常驻角标。
- 刷新失败或达到软件索引限额，保留旧索引及其更新时间；鉴权、限流或存储故障会暂停自动刷新，可处理问题后手动重试。媒体本身发生鉴权或解码等错误仍按原播放规则处理。成功扫描得到空目录时，新索引为空，当前 / 已预加载资源播放后停止。
- 仍串行请求元数据、共享 **64 MiB** 索引预算，不增加图片预加载张数。刷新是重新读取 OpenList 返回的目录，不绕过权限或强制清理服务端 / 网盘缓存；无法保证新增文件立即可见，也不是服务端增量变更订阅。

从较早版本更新：在设置中开启“参与测试版本”（新版位于“应用更新”），按需填写更新代理，再选择“检查 GitHub 更新”并点击“更新”。支持浏览器下载的版本可勾选“使用浏览器下载”，用浏览器打开安装包链接；关闭则使用应用内下载与安装流程。也可开启自动检测后重新进入应用。[预发布页面](https://github.com/LoliWolf/OpenListTV/releases/tag/v1.0.1-preview.11)。

## 大目录与全树随机轮播

轮播设置可开启“复用轮播索引（6小时）”。最近同一站点、账号、根目录和播放范围的有效快照可直接使用；6–24小时的旧快照先播放，同时在前台重扫；超过24小时重建。只保留最近一个范围；目录密码仅会话有效，不跨会话复用其快照。需要立即反映文件变化时勾选“本次重新扫描”，该勾选不会保存到下次。

本地连续翻页使用排序游标，减少大目录深页查询的扫描量；首次跳到没有书签的远处页仍可能较慢。排序、筛选结果不变，图片仍只预加载当前页和下一页。

新增可选“超大库公平抽样”：最多保留1万候选，达到1万后继续读取后面的目录。在稳定、无重复的完整分页输入下，各可播放文件具有相同入选概率；可能重复，不保证每张都播到。扫描未完成时只针对已读部分抽样。它改善大库参与机会，不减少首次完整扫描的网络请求。原来的“全目录树随机”仍保留完成后每轮不重复的规则。

索引按批读取最多500条元数据，图片列表与缩略图仍只加载当前页和下一页。浏览旧目录的索引可自动淘汰，不影响账号、播放进度或本机下载。

“全目录树随机”不必等整个目录建完索引，发现首批资源即可开始播放，扫描期间可能重复；扫描完成后，每轮内不重复。图片继续预加载下一张，慢网时保留当前画面。

总索引磁盘预算仍为64 MiB。原“全目录树随机”模式候选最多10万项，达到预算后继续轮播已发现资源，控制栏显示“未覆盖全部范围”；超限后剩余资源不会自动补入。若要完整逐轮播放，可从更具体的子目录开始；若要让超大库后面的资源也有入选机会，可选公平抽样。首次扫描或媒体播放发生真正的磁盘故障、登录失效、限流或网络错误仍需暂停处理；可选刷新失败保留旧索引。

## 画面比例、图片缩放与旋转

播放控制栏的“更多”中选择“画面设置”：视频可选择原始比例完整显示、铺满裁切、拉伸全屏、16:9 或 4:3。后两项把视频显示在指定比例的区域内；强制比例可能使画面变形。该选择会保存，选择原始比例可恢复。

图片提供放大、缩小、左右旋转和恢复原图。缩放范围 1–4×，旋转每次 90°；不修改服务器文件，也不额外下载高清原图。放大后选择“移动画面”，用方向键移动，确认键再次打开调整菜单，返回键退出移动模式。

调整图片时会暂停轮播，结束后手动“继续”；停止定时不受影响。换到另一张图片会恢复默认显示，同一图片横竖屏切换保留调整。

## 左右长按快进／快退

点播视频或音频时，收起控制栏后按左右键：短按小幅跳转，按住越久目标进度移动越快，松开后定位到目标时间。控制栏显示时左右仍用于按钮导航；图片和轮播仍用左右切换文件。

长按时显示目标时间，暂时保持当前画面；松键只进行一次实际跳转，不连续请求视频片段或额外生成预览图。返回键取消本次定位，原本暂停的资源定位后仍暂停。失去焦点、Home 或退出会停止操作，返回后需手动继续。未知时长或不可定位的资源不支持此功能。

## 更新设置与安装

- “自动检测更新（每次启动）”：开启后每次进入应用检查一次；有更新弹窗，无更新或失败轻提示。翻目录、旋转或从安装流程返回不会反复检查，播放过程中延后提示。
- “参与测试版本”：默认关闭；打开后同时检查已发布的正式版与预发布版，按版本号选择最新可用 APK。不包含草稿或 GitHub Actions 临时构建，不会提示降级。
- “使用浏览器下载”：默认关闭。开启后点击“更新”会用浏览器打开 APK 下载链接，不在应用内下载或唤起安装；保存位置与后续安装由浏览器及系统处理。没有可用浏览器时可复制链接。开关在重启和覆盖安装后保留。
- “配置更新代理”：留空为直连，仅影响 GitHub 检查和更新包下载，OpenList 登录、资源访问和资源下载均不受此设置影响。

代理有两种模式：

| 模式 | 地址格式 |
| --- | --- |
| 网络代理 | `http://主机:端口` 或 `socks5://主机:端口`，不含账号密码和路径 |
| GitHub 加速前缀 | `https://加速站/`，必须同时支持 GitHub API 和附件地址转发 |

例如局域网网络代理可填写 `http://192.168.1.2:7890`；`127.0.0.1` 指运行 OpenList TV 的安卓设备自身，不是你的电脑。只支持下载附件、不能转发 API 的加速站无法用于完整更新流程。代理失败会提示，不偷偷切换直连，也不关闭 HTTPS 证书校验。

浏览器不能继承应用内 HTTP/SOCKS5 网络代理，会使用浏览器自己的网络设置；HTTPS 加速前缀会保留在下载链接中。浏览器模式不经过应用内 APK 校验，安装由系统处理，也不能绕过设备的安装限制。

关闭“使用浏览器下载”时，发现新版本后点“更新”，应用会前台下载安装包，检查长度、可用的发布摘要、包名、版本和签名信息，随后自动打开系统安装流程。第一次可能需要去系统页面允许 OpenList TV 安装应用，授权后返回即可继续；最终安装仍需你确认。系统不提供安装入口或限制安装时，按提示使用设备支持的方式处理，不卸载旧版来绕过问题。

应用内 APK 下载期间暂停资源传输；退出前台则取消更新下载，下次可重新点击更新。已准备好的包会在再次核对后复用。测试版本可能不稳定，关闭“参与测试版本”不会自动降级或删除配置。

## 当前目录搜索与类型筛选

资源页选择“搜索”，输入文件名关键词，在“文件类型”中选择全部、图片、视频、音频、文件夹或其他文件，再按“应用”。关键词与类型可组合，英文大小写不敏感，中文直接匹配；`%`、`_` 等按普通字符处理。

搜索包含当前目录全部已索引条目，不仅是当前页；不扫描子目录。结果继续按当前排序显示，缩略图仍只保留当前页和下一页。点播的前后项也遵循筛选结果。“清除”恢复完整目录。

筛选是临时视图状态，重启或切换站点清除；不会修改服务器文件，也不会改变轮播范围。

## 定时停止轮播

在轮播设置选择“定时停止”后编辑分钟数，范围 0–1440，0 表示关闭。计时从开始轮播起算，加载和暂停也计时；到时退出轮播并释放播放资源，不关闭设备。

播放控制栏“更多”中的“定时停止”可重新设定当前会话的截止时间，或填 0 关闭；这不会改动下次轮播的默认参数。Home/休眠后不在后台唤醒，返回应用时若已到期则结束轮播，不自动重播。

## 播放信息

播放控制栏“更多”中选择“播放信息”，显示打开时快照，包括当前文件、显示位图尺寸/内存，或音视频轨道编码、分辨率、帧率、标称码率、声道和缓冲时长。信息缺失时不猜测数值，不后台持续监测。

HDR 显示能力与轨道 HDR 元数据分开显示；它们不代表投影面板实际输出的测量结果。信息中不显示媒体签名地址或登录凭证。

## 下载和离线打开

1. 列表选中文件后，长按遥控器确认键、按菜单键或触控长按，选择“下载文件”。无需遥控器具备专门的菜单键；资源页“更多 → 下载”也提供当前选中项及本机下载入口。
2. 确认后保存到“本机下载”。仅一个传输任务，64 KiB 流式缓冲，不把整文件装入内存；本机需保留至少 64 MiB 空闲空间。
3. 可查看进度、暂停、继续或重试。播放、退出前台或休眠会暂停传输，返回后需手动继续。
4. “本机下载”里的已完成图片、音乐和视频可离线打开；登录页、连接中/失败页也有入口，不需要服务器在线。文件能否解码仍取决于设备。
5. “导出到 U 盘 / 其他位置”使用系统文件选择器。部分电视没有该能力，仍可本机离线打开；导出失败或中断时请检查目标位置的未完成文件。

续传是有条件的：强 ETag、最终资源地址身份与范围响应必须一致；链接刷新、驱动不支持或无法确认文件一致性时从头下载。未完成文件不会作为完成文件播放。

支持单个文件，不下载整目录，不离线打包 HLS/DASH 分片流，不做后台自动同步。下载文件大小按存储空间限制；图片显示仍受 128 MiB 输入预算及采样内存预算约束。最多保留 100 条下载记录，可确认后删除本机副本以释放空间。

清缓存、退出账号和覆盖安装不会删除已下载副本；退出账号后仍可访问本机副本。未完成下载需登录原站点账号后继续。卸载应用会删除应用私有下载；重要文件可先导出。删除本机文件不影响服务器原文件。

## preview.1 已包含

- GitHub 更新检测（其旧每日一次/浏览器下载方式已由 preview.3 上述流程替代）。
- 系统原生 HDR 视频链路，以及符合条件的 Android 14+ Ultra HDR 图片显示；不引入软件视频转码器。
- 图片输入上限 128 MiB；单文件超限跳过，轮播可继续；实际磁盘不足仍暂停。
