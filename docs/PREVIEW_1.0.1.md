# 1.0.1 本地预览版

版本 `1.0.1-preview.2`，仅本地交付，未发布 GitHub。沿用原包名与签名，直接覆盖安装即可；不要卸载或清应用数据。已发布的稳定版仍是 1.0.0。

## 当前目录搜索与类型筛选

文件列表选择“搜索 / 筛选”，输入文件名关键词并选择全部、图片、视频、音频、文件夹或其他文件，再按“应用”。关键词与类型可组合，英文大小写不敏感，中文直接匹配；`%`、`_` 等按普通字符处理。

搜索包含当前目录全部已索引条目，不仅是当前页；不扫描子目录。结果继续按当前排序显示，缩略图仍只保留当前页和下一页。点播的前后项也遵循筛选结果。“清除”恢复完整目录。

筛选是临时视图状态，重启或切换站点清除；不会修改服务器文件，也不会改变轮播范围。

## 定时停止轮播

轮播设置增加“定时停止轮播”输入框，单位为分钟，范围 0–1440，0 表示关闭。计时从开始轮播起算，加载和暂停也计时；到时退出轮播并释放播放资源，不关闭设备。

播放控制栏的“定时停止”可重新设定当前会话的截止时间，或填 0 关闭；这不会改动下次轮播的默认参数。Home/休眠后不在后台唤醒，返回应用时若已到期则结束轮播，不自动重播。

## 播放信息

播放控制栏选择“播放信息”，显示打开时快照，包括当前文件、显示位图尺寸/内存，或音视频轨道编码、分辨率、帧率、标称码率、声道和缓冲时长。信息缺失时不猜测数值，不后台持续监测。

HDR 显示能力与轨道 HDR 元数据分开显示；它们不代表投影面板实际输出的测量结果。信息中不显示媒体签名地址或登录凭证。

## 下载和离线打开

1. 列表选中文件后，长按遥控器确认键、按菜单键或触控长按，选择“下载文件”。无需遥控器具备专门的菜单键；顶部“下载”也提供当前选中项及本机下载入口。
2. 确认后保存到“本机下载”。仅一个传输任务，64 KiB 流式缓冲，不把整文件装入内存；本机需保留至少 64 MiB 空闲空间。
3. 可查看进度、暂停、继续或重试。播放、退出前台或休眠会暂停传输，返回后需手动继续。
4. “本机下载”里的已完成图片、音乐和视频可离线打开；登录页、连接中/失败页也有入口，不需要服务器在线。文件能否解码仍取决于设备。
5. “导出到 U 盘 / 其他位置”使用系统文件选择器。部分电视没有该能力，仍可本机离线打开；导出失败或中断时请检查目标位置的未完成文件。

续传是有条件的：强 ETag、最终资源地址身份与范围响应必须一致；链接刷新、驱动不支持或无法确认文件一致性时从头下载。未完成文件不会作为完成文件播放。

支持单个文件，不下载整目录，不离线打包 HLS/DASH 分片流，不做后台自动同步。下载文件大小按存储空间限制；图片显示仍受 128 MiB 输入预算及采样内存预算约束。最多保留 100 条下载记录，可确认后删除本机副本以释放空间。

清缓存、退出账号和覆盖安装不会删除已下载副本；退出账号后仍可访问本机副本。未完成下载需登录原站点账号后继续。卸载应用会删除应用私有下载；重要文件可先导出。删除本机文件不影响服务器原文件。

## preview.1 已包含

- GitHub 稳定版更新检测：可手动检查，也可关闭每日一次前台自动检查；不自动下载安装。
- 系统原生 HDR 视频链路，以及符合条件的 Android 14+ Ultra HDR 图片显示；不引入软件视频转码器。
- 图片输入上限 128 MiB；单文件超限跳过，轮播可继续；实际磁盘不足仍暂停。
